Install

Linux packages come from repositories this project publishes, so every later version arrives with the rest of your system updates.

Everything, in one go

Adds every BotMaker repository, then installs the 4 packaged tools. Drop any name from the last line to leave that one out. One key signs all of them, so apt needs one keyring.

Fedora · RHEL

sudo curl -fsSL -o /etc/yum.repos.d/botmaker-studio.repo https://botmakerdev.github.io/botmaker-studio/botmaker-studio.repo
sudo curl -fsSL -o /etc/yum.repos.d/botmaker.repo https://botmakerdev.github.io/botmaker-cli/botmaker.repo
sudo curl -fsSL -o /etc/yum.repos.d/botmaker-dashboard.repo https://botmakerdev.github.io/botmaker-dashboard/botmaker-dashboard.repo
sudo curl -fsSL -o /etc/yum.repos.d/botmaker-remote-server.repo https://botmakerdev.github.io/botmaker-remote-server/botmaker-remote-server.repo
sudo dnf install botmaker-studio botmaker botmaker-dashboard botmaker-remote-server

Debian · Ubuntu

sudo install -d -m 755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/botmaker.asc https://botmakerdev.github.io/botmaker-studio/botmaker.asc
echo "deb [signed-by=/etc/apt/keyrings/botmaker.asc] https://botmakerdev.github.io/botmaker-studio/deb stable main" | sudo tee /etc/apt/sources.list.d/botmaker-studio.list
echo "deb [signed-by=/etc/apt/keyrings/botmaker.asc] https://botmakerdev.github.io/botmaker-cli/deb stable main" | sudo tee /etc/apt/sources.list.d/botmaker.list
echo "deb [signed-by=/etc/apt/keyrings/botmaker.asc] https://botmakerdev.github.io/botmaker-dashboard/deb stable main" | sudo tee /etc/apt/sources.list.d/botmaker-dashboard.list
echo "deb [signed-by=/etc/apt/keyrings/botmaker.asc] https://botmakerdev.github.io/botmaker-remote-server/deb stable main" | sudo tee /etc/apt/sources.list.d/botmaker-remote-server.list
sudo apt-get update && sudo apt-get install botmaker-studio botmaker botmaker-dashboard botmaker-remote-server

Upgrading is your package manager's job from here. Every tool arrives with the rest of your system updates — sudo dnf upgrade or sudo apt-get update && sudo apt-get upgrade. To move only these: sudo dnf upgrade botmaker-studio botmaker botmaker-dashboard botmaker-remote-server, sudo apt-get install --only-upgrade botmaker-studio botmaker botmaker-dashboard botmaker-remote-server.

These are upgrade channels carrying the latest release only. The Android apps are not here: a phone installs its own way, below.
