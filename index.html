BotMaker

Build a bot out of blocks, run it against an emulator or a window, publish it. Everything below is one project; take the pieces you need.

Install

BotMaker Studio

The IDE: build a bot out of blocks, run it against an emulator or a window, publish it to the gallery.

Latest release v1.1.5

sudo curl -fsSL -o /etc/yum.repos.d/botmaker-studio.repo https://botmakerdev.github.io/botmaker-studio/botmaker-studio.repo
sudo dnf install botmaker-studio

apt, the signing key and the checksums are on the project page.

Windows installer (.msi), AppImage and portable archives are on the release page.
