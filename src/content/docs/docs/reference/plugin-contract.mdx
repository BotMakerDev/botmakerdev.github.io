This page will walk through `botmaker-studio-api`, the contract between Studio and a plugin: how a plugin declares
its blocks, value types, windows, overlays and assistant tools, and what Studio gives it in return. Until then, the
contract's [javadoc](https://jitpack.io/com/github/BotMakerDev/botmaker-studio-api/latest/javadoc/) describes every
type, and [Make and publish a plugin](/docs/how-to/make-a-plugin/) starts you from a working example.
