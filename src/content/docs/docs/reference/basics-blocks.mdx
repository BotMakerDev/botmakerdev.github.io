This page will list every value type [Basics](/plugins/com.botmaker.basics/) adds — durations, times, dates,
colours, paths and the rest — with the editor Studio shows for each and the Java it writes. Basics brings no blocks
of its own: it makes the variable blocks offer those types. Its plugin page has the short version.
