This tutorial will take you from a blank project with the [BotMaker SDK](/plugins/com.botmaker.sdk/) ticked to a
bot that plays one loop of a game on its own: choosing the game's window, capturing the pictures it clicks,
drawing its screens and activities, and running it with the run overlay showing what it sees. Until it is written,
the SDK's page describes each of those parts.
